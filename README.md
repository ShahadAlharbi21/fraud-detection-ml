# fraud-detection-ml
### Dataset
The dataset used in this project is the "Credit Card Fraud Detection" dataset from Kaggle. You can find and download it from [here](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud).

**Note**: The dataset is **not included** in this repository. You will need to download it separately from Kaggle.

### Instructions for Downloading the Dataset:
1. Go to the Kaggle dataset page: [Credit Card Fraud Detection](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud).
2. Sign in to your Kaggle account (or create one if you don’t have one).
3. Click on the **"Download"** button to download the dataset as a ZIP file.
4. Extract the ZIP file, and place the `creditcard.csv` file in the **same directory** as your Jupyter notebook.
